Niloc

Major Project · 2019

Programmer / Project Manager · team of 6 (+3 outsourced)

A 2–4 player local multiplayer game blending MOBA-style ability play (think DOTA 2) with fully customizable ability sets — players build their kit from twelve abilities across four sets instead of picking a fixed character.

Built a Scriptable-Object-driven ability framework for fast, designer-friendly iteration, a pooled particle/projectile system (PoolManager), and a custom complex-collider tool inspired by Unreal's FBX static mesh pipeline.

WorldCraft

Advanced Games Implementation Project · 2019

Solo project

A Minecraft-inspired technical demo: procedurally generated, voxelized terrain in an infinite world, built from scratch in Unreal Engine 4.

Terrain is generated from simplex noise sampled across multiple octaves, stored in a custom chunked voxel data structure, and rendered efficiently using instanced static meshes for repeated elements like grass.

  • C++
  • Unreal Engine 4
  • Procedural Generation
